# MagazAIno — app per Android

Il magazzino semplice per le associazioni di volontariato: vestiario, gadget, ristoro, ausili e materiali,
con dotazioni dei volontari, richieste con notifica e scadenze. Progetto **senza scopo di lucro**, gratuito
per le associazioni.

## Scarica

**[Scarica l'ultima versione (MagazAIno.apk)](https://github.com/bdbais/magazaino-releases/releases/latest/download/MagazAIno.apk)**
— oppure dal telefono apri <https://magazaino.bais.info/app>

1. Scarica il file e aprilo quando il download è finito.
2. Se il telefono chiede il permesso, tocca **Impostazioni** e attiva **Consenti da questa fonte**.
3. Tocca **Installa**.

Serve Android 7 o successivo. Quando esce una versione nuova, l'app lo segnala da sola.
Su iPhone non serve scaricare niente: apri <https://magazaino.bais.info> in Safari e scegli
**Condividi → Aggiungi alla schermata Home**.
